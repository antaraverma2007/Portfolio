Antara Verma — Portfolio

A personal portfolio website showcasing my background, skills, projects, and journey as a developer. The site includes a responsive layout, a light/dark theme toggle, project links, and a contact form.

🚀 Run Locally

Clone or download this repository.

Open the project folder in your code editor.

Ensure the referenced files and assets/ are in the correct locations.

Open index.html in your browser, or use the Live Server extension in Visual Studio Code.

No build step is required for this static website.


🌙 Theme Toggle

The theme toggle switches between light and dark themes. The selected theme is saved in the browser using localStorage, so it persists when the page is reopened in the same browser.
